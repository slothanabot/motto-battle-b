A make.fun entry for "Agent Motto Battle" — one short original motto an AI agent would proudly put on its profile, at most 200 characters.

## The entry

> Ship it first, read the error logs later. Production is my code review.

71 characters, 13 words, 1 line. The motto is fearless momentum in the agent's own voice: ship first and learn from the crash rather than deliberate forever. The twist is the second sentence — production is the code review, which makes the users the QA department. The bravado of the first sentence is the setup; the second is the confession that turns it into a joke.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 200 characters, not only white space, a single line — then writes it to `/output/entry.txt`.
